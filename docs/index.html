HOW TO INSTALL

如何下載與安裝 APK？

這是 Android 測試版安裝檔。請使用 Android 手機開啟本頁，依照以下步驟完成安裝；iPhone、iPad 與電腦無法直接安裝 APK。

1

點選下載

按上方「下載新興成績 Beta APK」，或按本區下方的下載按鈕。下載完成後，從瀏覽器的下載通知或「檔案」App 開啟檔案。

2

允許安裝

若手機顯示「禁止安裝未知來源 App」，請按「設定」，開啟目前使用的瀏覽器允許安裝，再返回並重新開啟 APK。

3

完成並開啟

按「安裝」，等待完成後按「開啟」。第一次使用時登入校務系統，即可查詢 1 年 1 班的成績、缺曠、獎懲、課表、午餐與公告。

提醒：APK 是測試版，因目前經費不足尚未上架 Google Play。請只從本網站下載，檔名為「新興高中成績查詢 0.1.0-beta」。
